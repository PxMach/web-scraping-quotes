# 📄 Quotes Scraper (Python + BeautifulSoup)
📌 Description

Ce projet est un script Python qui permet de scraper des citations (quotes) depuis le site :
https://quotes.toscrape.com/

Il extrait :

les citations
les auteurs
et les enregistre dans un fichier CSV.
🚀 Fonctionnalités
Récupération automatique des données depuis une page web
Parsing HTML avec BeautifulSoup
Extraction des citations et auteurs
Export des données dans un fichier CSV
🛠️ Technologies utilisées
Python 🐍
Requests
BeautifulSoup (bs4)
CSV (module standard Python)

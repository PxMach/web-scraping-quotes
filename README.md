# 📄 Quotes Scraper (Python + BeautifulSoup)

## 📌 Description:

Ce projet est un script Python qui permet de scraper des citations (quotes) depuis le site :
https://quotes.toscrape.com/

Il extrait:

les citations, les auteurs et les enregistre dans un fichier CSV.

## 🚀 Fonctionnalités:

1-Récupération automatique des données depuis une page web

2-Parsing HTML avec BeautifulSoup

3-Extraction des citations et auteurs

4-Export des données dans un fichier CSV

## 🛠️ Technologies utilisées:

1-Python 🐍

2-Requests

3-BeautifulSoup (bs4)

4-CSV (module standard Python)

📦 Installation
Cloner le repository :
[git clone https://github.com/ton-username/quotes-scraper.git](https://github.com/PxMach/web-scraping-quotes.git)

Installer les dépendances :

pip install -r requirements.txt
